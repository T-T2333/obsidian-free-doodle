## Fixes

- **Release the ONNX Runtime session on unload** — prevents native inference resources from surviving a plugin disable/reload and avoids a late first-use load recreating a disposed session.
- **Keep recognition batches stable** — recognition is serialized and each run uses a stroke snapshot, so writing while the model is downloading or recognizing cannot mix new strokes into the previous character.
- **Reject invalid cached WASM** — validates the downloaded runtime before initialization and falls back cleanly when the cache is corrupted.
- **Close stale handwriting popovers** — clearing handwriting data no longer leaves an unusable candidate picker open.
