## Fixed

- **Standalone board style controls actually apply now**: width presets (细/中/粗) and the opacity slider wrote to unused local fields — strokes read `brushes[curBrush].size/opacity`. Both now update the active brush config (and mirror pen size to the legacy `penSize` setting); preset highlight compares against the real brush size
- **Highlighter auto-translucency fixed (both surfaces)**: switching to 荧光笔 when opacity > 60% now lowers the *brush* opacity (the value strokes actually use), not a dead `tool.opacity` field, and persists
- **"Default pen size" setting no longer dead**: it only wrote the legacy `penSize` field, while strokes read `brushes.pen.size`. Both settings UI paths now keep them in sync; on load the effective pen brush size wins
- **Style changes no longer lost within 350 ms of overlay destroy**: pending debounced settings save is flushed in `destroy()`
- **Unsaved strokes no longer dropped on view reuse / file switch**: sweep and drop-overlay paths now `destroy(true)` so dirty ink is written to the old file before the overlay is discarded
- **Board PNG export in reading mode**: no longer tries to insert `![[…]]` into an inactive editor; shows the saved path instead. Folder creation tolerates concurrent-create races
