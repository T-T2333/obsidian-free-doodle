## Fixes

- **Diagnostics UI no longer cramped** — the log textarea was rendered into the settings row's narrow control column (and nested a duplicate “诊断日志” heading). It now spans the full row with a proper monospace box and a clean 刷新 / 复制全部 / 清空 button row. Live status also shows current tool mode + handwriting batch size.
- **Handwriting entry is discoverable** — entering handwriting mode shows a one-line hint (write one character, then click ✨). Command palette: **手写识别模式（写一个字后识别为美化字体）** jumps straight into the mode once annotate is on. Tooltips spell out the two-step flow.
- **More diagnostics** — mode switches, strokes entering the handwriting batch, recognize attempts (including empty-batch clicks) and candidate results are all logged so the Diagnostics panel can show exactly what happened.
