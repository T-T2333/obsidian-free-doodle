> ✏️ Excalidraw 风格工具栏 + 笔迹美化 + 语音转文字

## ✨ Added

- **Excalidraw 风工具栏**：紧凑 Dock 布局（笔 / 荧光笔 / 形状 / 橡皮 / 样式 / 语音 / 撤销 / 清空 / 完成），颜色、粗细、不透明度全部收进「样式」弹出面板，不再占用长条空间；窄面板自动换行
- **更多形状**：直线、箭头、矩形、椭圆、菱形 —— 点形状按钮弹出选择菜单，当前形状高亮；所有形状支持文字锚定跟随与整笔擦除命中
- **笔迹优化**（类似手写笔记 App 的字迹美化）：自由笔迹落笔后自动去抖动并做两轮 Chaikin 曲线拟合，字迹圆润流畅；可在样式面板中随时开关
- 🎤 **语音转文字**：点击麦克风说话，识别结果实时插入当前笔记光标处（基于系统 Web Speech API，环境不支持时按钮自动隐藏）

## Changed

- 绘制预览与最终渲染统一为同一路径：划线过程即最终效果，无松手跳变
- 独立画板同步获得以上全部新工具（语音除外）
