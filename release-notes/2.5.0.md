## Improvements

- **Handwriting recognition rewritten on PP-OCRv5** — a real OCR model replaces the old stroke-template matcher as the primary engine (ONNX Runtime Web, wasm). First use downloads the model + runtime into the plugin folder once (~28 MB, multi-mirror: jsDelivr / npmmirror), then works fully offline. HanziLookupJS remains as an automatic fallback if the download or load fails.
- **Safer auto-replace** — after your ~0.9s pause, the top candidate is only applied when confidence is high enough (score ≥ 0.5). Lower-confidence results open the candidate picker instead of silently swapping in the wrong character. The sparkle button still forces the picker.
- **Diagnostics** — every recognition logs the active engine (`backend=ppocr` / `hanzi`) and per-candidate scores, so the settings Diagnostics panel shows exactly what was matched.
