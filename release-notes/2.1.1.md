## Fixed

- **Performance**: drawing is now smooth even with many strokes. Committed ink renders once into an offscreen cache; the live cursor path only blits that cache plus the active stroke each frame (previously every frame repainted all strokes with anchor lookups)
- Live beautification is capped (length + single smoothing round) to keep input latency low; full two-round smoothing still applies on commit
