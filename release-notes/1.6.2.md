## Changed

- Adopt the declarative settings API (`getSettingDefinitions`) so plugin settings appear in Obsidian's settings search on Obsidian 1.13+
- Caret hit-testing now prefers the standard `caretPositionFromPoint`, falling back to the legacy API only on older engines
- Settings search entries are bilingual (English / 中文)
