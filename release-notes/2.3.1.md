## Fixed

- **Aborted strokes are no longer lost**: `pointercancel` (palm contact, system gesture) now commits the partial stroke instead of discarding it — on both note overlay and board
- **Tiny-shape ghost**: discarding a too-small shape drag (<4px) left its preview pixels on canvas — now repaints immediately
- **Multi-pointer hygiene**: pointerup/pointercancel from a pointer that never started the stroke no longer commits it early; a stylus won't hijack a stroke already drawn by mouse, but CAN take over from a palm/touch stroke (palm-first case)
- **Stroke-eraser drag uses coalesced samples**: fast drags no longer skip strokes between event samples; one repaint per frame instead of per sample
- **Eraser/stroke-eraser now refresh undo/redo buttons** (overlay + board) after removals; board clear() and stroke commit also refresh them (redo stayed lit after drawing)
- **Auto-fit strips stale pen width/pressure arrays** when converting freehand → line/rect/ellipse; serialization drops `w`/`pr` if length no longer matches points (smaller, safer payloads)
- **fitLast undo stack capped at 50** like everywhere else; fixed a stray indentation glitch
