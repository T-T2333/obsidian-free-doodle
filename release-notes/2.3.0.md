## Added — tablet & stylus support 平板与触控笔支持

- **Pressure sensitivity 压感书写**: pen/pencil/ball strokes vary width with stylus pressure; for the fountain pen pressure multiplies with the existing speed-based width. Stored per-point (`pr`), survives save/reload. Toggle in settings (default on)
- **Palm rejection 防掌触**: touch input is ignored for 1s after any stylus activity (hover or contact), so resting your palm won't draw; pen pointers are accepted even when a palm touch claimed primary status first
- **Coalesced pointer events 合并采样**: uses `getCoalescedEvents()` so 120Hz+ stylus streams are captured fully — faster, smoother strokes (and denser laser trails)
- **Tablet CSS**: disables long-press callout & text selection on the interactive canvas and board

## Fixed

- Overlay stroke-eraser drag was dead code (the drag branch sat below an early return) — dragging with the stroke eraser now removes strokes continuously; both surfaces also require the button to be held (no hover-erase)
