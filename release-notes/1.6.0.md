Draw and annotate directly on your Obsidian notes — ink lives on a separate layer above the text and follows it as your note evolves.

This is the first community-ready release of **Free Doodle**, polished against the official plugin review guidelines.

## ✨ Features

### In-note annotation
- Press `Ctrl+D` or click the highlighter ribbon icon to draw right on top of note content
- Works in both editing and reading views
- Ink renders on a transparent layer above the text — your text stays fully editable at all times

### Tools
- ✏️ **Pen** — smooth quadratic strokes, width 1–40 px
- 🖍️ **Highlighter** — translucent marker that keeps text readable underneath
- ⬜ **Rectangle** — drag to box any content
- 🧽 **Pixel eraser** — erase exactly what you sweep over
- ✂️ **Whole-stroke eraser** — click or swipe to delete entire strokes
- 🎚️ **Opacity slider** — 10%–100%, applies per stroke
- ↩️ Undo (`Ctrl+Z`), clear-all, per-note cleanup commands

### Text anchoring
Every stroke remembers the paragraph/line it was drawn on. When you add/remove properties or paragraphs, or resize panes so text reflows, ink follows the anchored text instead of staying behind.

### Persistence without clutter
- Strokes are stored as compact base64 JSON in a `free-doodle` frontmatter property **inside the note itself**
- No sidecar files — annotations travel with your notes through sync services
- The property removes itself automatically when all ink is cleared, leaving zero trace
- A one-click command cleans up empty leftover properties across the whole vault

### Reading mode & embeds
- Reading view automatically overlays saved ink, and you can annotate there too
- Doodles render inside embeds and page previews

### Standalone board
- Full-screen scratch pad sharing every tool above (open from plugin settings or the command palette)
- One-click PNG export: saved into a configurable vault folder, copied to the clipboard, and inserted at the cursor of the active note

## 🔧 Technical

- **Zero network requests** — everything is stored locally
- Passes the official `eslint-plugin-obsidianmd` rule set with 0 errors
- Release assets are built by GitHub Actions with **artifact provenance attestations**
- Requires Obsidian **1.7.2+**

## 中文

在 Obsidian 笔记上直接涂鸦、划线、圈注。墨迹作为独立图层叠加在文字上方，并随笔记内容变化自动跟随移动。

这是 Free Doodle 首个按官方插件审查指南打磨完成的社区版本。

### ✨ 功能一览

- **笔记内涂鸦**：`Ctrl+D` 或点击左侧荧光笔图标即可在正文上方标注，编辑 / 阅读模式均支持
- **五种工具**：
  - 钢笔（二次曲线平滑，1–40 px）
  - 荧光笔（半透明标记，文字清晰可读）
  - 矩形框选（拖拽圈住任意内容）
  - 像素橡皮擦（擦除划过的区域）
  - 整笔擦除（点一下或划过即删除整笔）
- **不透明度滑杆**：10%–100%，逐笔生效
- **撤销 / 清空 / 单笔记清除 / 全库空数据清理**一应俱全

### 📌 文字锚点跟随

每一笔会自动记录所在段落或行。当你增删属性区、增删段落、或拖动侧边栏导致文字重排时，墨迹会跟着锚定的文字一起移动，始终圈在该圈的字上。

### 💾 干净存储

- 墨迹以紧凑 base64 存入笔记自身 frontmatter 的 `free-doodle` 属性
- 无附属文件，随笔记同步走
- 清空墨迹后属性自动删除，不留痕迹；另提供全库清理命令处理历史遗留

### 🖥 独立画板

- 全屏画板，工具与笔记内完全一致（设置页或命令面板打开）
- 一键导出 PNG：存入指定文件夹 + 复制到剪贴板 + 插入当前笔记光标处

### 📖 阅读模式与嵌入

阅读视图自动叠加显示墨迹（也可直接在上面涂鸦）；嵌入引用与悬浮预览同样渲染。

### 🔧 技术说明

- **零网络请求**，所有数据仅存本地
- 通过官方 `eslint-plugin-obsidianmd` 全部规则检查（0 错误）
- Release 资产由 GitHub Actions 构建，附 **artifact provenance attestation** 构建来源证明
- 需要 Obsidian **1.7.2 及以上版本**
