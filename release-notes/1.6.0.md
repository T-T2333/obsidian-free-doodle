## Changed

- Raised minimum Obsidian version to **1.7.2** (required by `revealLeaf`)
- Plugin description and README are now bilingual (English + 中文), README rewritten with feature list and usage guide

### Fixed

- Removed default `Ctrl+D` hotkey to avoid conflicts; bind it manually in settings if you like
- All official review issues resolved: inline style assignments, manual HTML headings, bare timers, cross-window type checks, unsafe typings, deprecated APIs
- Opacity label now stays in sync when switching tools
- Rectangle dragging no longer flickers on long notes

### Build / Release

- Release assets are now built by GitHub Actions with artifact provenance attestations
- `versions.json` is no longer attached to releases (Obsidian reads it from the repository)
- Added `package-lock.json` so builds are reproducible
