> 🖌 多笔刷深度调参 · 几何自动拟合 · 文本标注 · 语音输入

## ✨ Added

### 六种笔刷，独立深度参数
- **钢笔**（速度感应粗细）/ **铅笔**（颗粒质感）/ **圆珠笔** / **马克笔**（宽头）/ **荧光笔**（半透明）/ **激光笔**（发光辉光）
- 每支笔独立保存 **粗细 / 不透明度 / 浓度 / 稳定性** 四项参数（样式面板内调节，自动持久化）
- 浓度：控制铅笔颗粒密度与马克笔叠层深浅；稳定性：控制去抖强度与平滑轮数

### 几何自动拟合
- 随手画的闭合图形自动判定并修正为**完美矩形或椭圆**；开放笔迹修正为**水平/垂直吸附的直线**
- 样式面板提供「自动拟合」开关；工具栏新增「ⓐ 一键修正」按钮，可将最后一笔即时拟合

### 文本标注工具
- 点击画布任意位置插入文字，统一使用笔记正文字体渲染，随锚点跟随移动

## Changed

- 工具栏重构：六种笔刷 + 形状/文本/橡皮 + 样式/语音/撤销/拟合/清空/完成，自动换行
- 设置页与设置搜索同步支持全部新选项
