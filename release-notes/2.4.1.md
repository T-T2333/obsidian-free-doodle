## Fixes

- **Handwriting recognize more reliable** — multi-mirror first-use data download (fastly/cdn jsdelivr, then GitHub raw) with format validation; clearer error notices when download or recognition fails.
- **No more stuck "识别中…"** — empty/invalid strokes and matcher edge cases now resolve (or reject with a timeout) instead of hanging forever; non-finite scores (NaN/−Infinity) are filtered from candidates.
- **Candidate popover stays on screen** — position is computed relative to the content element (clamped inside the view) instead of mixing viewport/canvas coordinates.
- **Batch kept when switching tools** — leaving the handwriting tool no longer discards your pending strokes, so the recognize button stays usable after switching away and back; strokes already undone/erased are dropped before matching.
