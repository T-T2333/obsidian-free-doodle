## Improved

- **Esc priority**: if a style/shape/eraser/text popover is open, Esc closes it first instead of exiting annotate mode
- **Laser loop idle optimization**: the render loop stops when idle (no trail points and button released) and restarts automatically on the next press — no wasted frames while the laser tool is merely selected
- Undo/redo button disabled states refresh after text annotations are committed
- README: removed references to the removed default `Ctrl+D` hotkey
