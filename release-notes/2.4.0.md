## New

- **Handwriting beautify (手写识别美化字)** — switch to the new handwriting tool (`languages` icon), write **one** Chinese character freehand (auto-fit is skipped so raw strokes are preserved), then click the sparkle icon. The stroke-based recognizer (HanziLookupJS, offline after first data download) offers 6 candidates; pick one to replace your handwriting with a neat glyph in a configurable beautify font (default: KaiTi/楷体). "保留手写" keeps the ink as-is. Works both in-note and on the standalone board.
- **New setting: Handwriting beautify font** — CSS font stack used for recognized characters.

## Notes

- First use of the recognizer downloads ~0.8 MB of stroke data (Make Me a Hanzi / Arphic PL) once into the plugin folder, then works offline. All other drawing stays fully offline.
- Recognition is stroke-based (not OCR), so one clear character at a time works best.
- HanziLookupJS is GPL-3.0; see README Credits.
