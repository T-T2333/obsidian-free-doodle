## Fixed

- **Ctrl+Z no longer hijacks text inputs**: with focus inside the text annotation box (or any input/contenteditable), Ctrl+Z performs native text undo instead of triggering ink undo in capture phase
- **IME composition Enter**: confirming Chinese/Japanese composition with Enter no longer immediately commits the half-finished text annotation (both surfaces)
- **Save race protection**: overlapping `vault.process` read-modify-write cycles are serialized with an in-flight guard + pending re-run; failed saves restore the dirty flag so the next action retries instead of silently dropping data; debounce timer skips redundant writes
- **Overlay text annotation now refreshes undo/redo buttons** and caps the undo stack at 50 (board already did)
- **clearAllForRemove also clears redo stack** — old strokes could be redone after "clear doodle data"
- **Voice input in reading mode** now shows a clear notice instead of silently failing (editor APIs are unavailable in preview mode)
